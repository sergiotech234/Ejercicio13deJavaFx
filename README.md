# Formulario de Dirección con Confirmación en Java

## Descripción

Este proyecto consiste en desarrollar una aplicación en **Java** con una interfaz gráfica que incluye un **campo de texto para introducir una dirección** y un botón de confirmación. Al pulsar el botón, la aplicación muestra un mensaje confirmando la dirección ingresada por el usuario.

El objetivo del ejercicio es practicar la captura de datos mediante formularios y la interacción con componentes gráficos usando **Swing**.

## Objetivos

- Crear un formulario con un campo de texto.
- Permitir al usuario introducir una dirección.
- Implementar un botón con gestión de eventos.
- Mostrar un mensaje de confirmación con la información introducida.
- Mejorar la interacción usuario–aplicación.

## Funcionamiento

1. Se inicia la aplicación.
2. Se muestra un formulario con un campo para introducir una dirección.
3. El usuario escribe la dirección deseada.
4. Al pulsar el botón:
   - Se obtiene el texto ingresado.
   - Se muestra un mensaje de confirmación con la dirección introducida.

## Ejemplo de uso

Formulario:

```text
Dirección:

[ Calle Principal 123 ]

      [ Confirmar ]
```

Al pulsar el botón:

```text
Dirección registrada: Calle Principal 123
```
